# Exploria API schemas

Pydantic v2 request models validate incoming data for the API routers. The schemas are imported by the relevant routers.

- `chatbot.py` — chatbot request.
- `cultural.py` — cultural-guide request.
- `budget.py` — budget analysis request/response.
- `expense_split.py` — group expense split request/response.
- `destination.py` — destination request and information shapes.
- `recommendations.py` — recommendation request.
- `events.py` — event-search request/response shapes.
- `travel_requirements.py` — travel checklist request.
- `common.py` — shared response shapes.

Install the dependencies from `requirements.txt`.
