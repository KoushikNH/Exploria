
# EXPLORER – Database Design

This folder contains the MongoDB database design for the EXPLORER travel platform.

## Folder Structure

- `schemas/` – Database collection schemas.
- `sample-data/` – Example documents for each collection.
- `documentation/` – Database design and technical documentation.

## Database Technology

- MongoDB Atlas
- BSON document-based database

## Planned Collections

1. users
2. profiles
3. destinations
4. experiences
5. albums
6. events
7. vehicles
8. bookings
9. trips
10. expenses
